# Talabat Home 🛒

نسخة مستقلة من تطبيق مشتريات بسيط تعمل على موبايلين (الزوج والزوجة) ويتواصل بينهما عبر الإنترنت.
مخصّصة لـ **هيثم سعد** (رمز `1111`) و**ولاء صلاح** (رمز `2222`)، بقاعدة بيانات ورابط وAPK منفصلين عن النسخة الأصلية.
الزوجة تبني الطلب، والزوج يستلمه ويحدّد ما اشتراه، وفي النهاية يظهر تقرير بالمشتري وغير المشترى.

## المكوّنات

| المجلد | الوظيفة |
| --- | --- |
| `server/` | سيرفر FastAPI: دخول بـ PIN، قوائم، أصناف، صور، طلبات، إشعارات |
| `web/` | واجهة عربية RTL (HTML/CSS/JS) تعمل كـ PWA |
| `capacitor/` | غلاف Capacitor لتحويل الواجهة إلى APK |
| `scripts/` | أدوات تحضير أدوات البناء وبناء الـ APK |
| `Dockerfile`, `render.yaml`, `fly.toml` | نشر السيرفر على سحابة مجانية |

البيانات (القوائم، الصور، الطلبات) تُحفظ في قاعدة بيانات واحدة على السيرفر:
SQLite محلياً أو PostgreSQL على السحابة. لا توجد بيانات خاصة على الموبايل سوى رمز الجلسة والمسودة.

## 1) التشغيل محلياً للتجربة السريعة

```powershell
cd server
.\start_local.bat
```

افتح على الكمبيوتر: `http://localhost:8000`

عند أول تشغيل تظهر رموز الدخول في الطرفية (مثلاً `الزوج: 1234` و`الزوجة: 5678`).
يمكنك تحديدها بنفسك قبل التشغيل:

```powershell
$env:HUSBAND_PIN="1234"
$env:WIFE_PIN="5678"
.\start_local.bat
```

لتجربة الموبايل على نفس الشبكة: افتح `http://IP-الكمبيوتر:8000` من الموبايل.
للاتصال من الإنترنت استخدم النشر السحابي في القسم التالي.

الاختبارات الآلية:

```powershell
cd server
.\.venv\Scripts\python -m pytest tests -q
```

## 2) النشر على سحابة مجانية

### أ) Vercel — مجاني وبدون بطاقة (موصى به)

السيرفر الحالي منشور على `https://talabat-home.vercel.app`. لإعادة النشر أو تعديله:

1. افتح https://vercel.com/new وسجّل الدخول بـ GitHub.
2. استورد مستودع `msz11911/talabat-home` (Framework: **Other**، Root Directory: `.`).
3. أضف المتغيرات: `DATABASE_URL` (رابط Neon)، `APP_SECRET` (نص ثابت)، `HUSBAND_PIN`، `WIFE_PIN`، و`DATA_DIR=/tmp`.
4. اضغط **Deploy**. ملفات الواجهة مكرّرة في `public/` و`server/web/` ليتمكن FastAPI من تقديمها على Vercel.

> ملاحظة: قاعدة البيانات على Neon، والجلسات موقّعة بـ `APP_SECRET` ثابت حتى لا تسقط عند إعادة النشر.

### ب) PythonAnywhere — مجاني 100% وبدون بطاقة

لا يحتاج بطاقة بنكية ولا قاعدة بيانات خارجية؛ قاعدة SQLite تُحفظ على قرص الحساب.

1. سجّل في [PythonAnywhere](https://www.pythonanywhere.com/registration/register/beginner/) واختر **Beginner / Create a free account**.
2. من صفحة **Account** انشئ **API token** (اضغط «Create new API token»).
3. افتح تبويب **Consoles** وابدأ **Bash**، ثم نفّذ سطراً واحداً:
   ```bash
   rm -rf ~/talabat-home && git clone https://github.com/msz11911/talabat-home.git ~/talabat-home && bash ~/talabat-home/scripts/setup-pa.sh
   ```
4. يثبّت السكربت الحزم ويُنشئ الموقع تلقائياً. افتح:
   ```
   https://اسمك.pythonanywhere.com/api/health
   ```
   يجب أن يظهر `{"ok":true,"app":"Talabat Home","version":"1.0.0"}`.
5. الرمزان الافتراضيان: الزوج `1234` والزوجة `5678`. لتغييرهما عدّل `~/talabat-home/start.sh` ثم أعد تحميل الموقع:
   ```bash
   pa website reload --domain اسمك.pythonanywhere.com
   ```

> ملاحظة: الحساب المجاني يمنح web app واحداً وذاكرة 512MB، وهذا يكفي تماماً للتطبيق.
> عند تحديث الكود على GitHub، نفّذ في Bash:
> `cd ~/talabat-home && git pull && pa website reload --domain اسمك.pythonanywhere.com`

### ج) Render + Neon (يحتاج بطاقة للتحقق من الهوية)

1. أنشئ حساباً على [Neon](https://neon.tech) وقاعدة بيانات PostgreSQL مجانية،
   وانسخ رابط الاتصال `DATABASE_URL`.
2. ارفع هذا المجلد إلى GitHub.
3. على [Render](https://render.com) اختر **Blueprint** واشر إلى `render.yaml`.
4. في متغيرات البيئة أدخل:
   - `HUSBAND_PIN` و `WIFE_PIN` (أرقام، 4 على الأقل) — أو اتركهما فارغين واقرأ الرموز من سجلات Render عند أول تشغيل.
   - `DATABASE_URL` = رابط Neon الذي نسخته.
   - `APP_SECRET` يُولَّد تلقائياً من `render.yaml`.
5. بعد النشر ستتحصل على رابط مثل `https://talabat-home.onrender.com`.
   افتحه على الموبايلين، وسجّل الدخول برمز كل دور.

> **مهم:** إذا ضبطت `HUSBAND_PIN` / `WIFE_PIN` كمتغيرات بيئة، فإن قيمتها تُطبَّق عند كل إعادة تشغيل
> وتُلغي أي تغيير أجريته من شاشة الإعدادات. بعد تغيير الرموز من التطبيق، احذف المتغيرين من Render وأعد النشر.

بديل: [Fly.io](https://fly.io) مع ملف `fly.toml` — القرص الدائم `talabat_data` يحفظ قاعدة SQLite:

```powershell
fly volumes create talabat_data --region ams --size 1
fly apps create talabat-home
fly secrets set HUSBAND_PIN=1234 WIFE_PIN=5678 APP_SECRET=نص-عشوائي-طويل
fly deploy
```

## 3) تثبيت التطبيق على الموبايل

### أ) PWA — الأسهل (بدون بناء)

افتح رابط السيرفر في Chrome على الأندرويد → قائمة Chrome ⋮ → **تثبيت التطبيق / Add to Home Screen**.
على آيفون: Safari → مشاركة ⬆️ → **إضافة إلى الشاشة الرئيسية**.

### ب) APK عبر Capacitor

1. حضّر الأدوات مرة واحدة (أو ثبّت Android Studio). يحتاج Capacitor 7 إلى **JDK 21**:

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\install-build-tools.ps1
   ```

2. قبل البناء، حدّد رابط السيرفر المنشور (يمكن تركه فارغاً وإدخاله لاحقاً من شاشة الدخول):

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\build-apk.ps1 -ApiBase "https://talabat-home.vercel.app"
   ```

   يمكن أيضاً تعديل `web/config.js` مباشرة:

   ```js
   window.TALABAT_API_BASE = "https://talabat-home.vercel.app";
   ```

3. ابني الملف (الأمر في الخطوة 2 يبنيه مباشرة؛ وبدون `-ApiBase` شغّل):

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\build-apk.ps1
   ```

   الناتج: `dist/TalabatHome-debug.apk`، ويُنسخ تلقائياً إلى `web/TalabatHome.apk` للتحميل.
   **النسخة الجاهزة الحالية للهاتفين:**
   [حمّل TalabatHome.apk](https://github.com/msz11911/talabat-home/raw/refs/heads/main/web/TalabatHome.apk)
   (انسخ الرابط في Chrome على الهاتف؛ قد تحتاج تفعيل «تثبيت من مصادر غير معروفة»).
   قبل التثبيت احذف النسخة القديمة حتى تُفعّل قناة الإشعار بالصوت الجديد.

> لتحديث الواجهة لاحقاً بدون إعادة بناء الـ APK، انسخ محتوى `capacitor.config.remote.example.json`
> إلى `capacitor.config.json` وبدّل الرابط، ثم أعد البناء مرة واحدة. بعدها سيحمّل التطبيق الواجهة من السيرفر دائماً.

## 4) دليل الاستخدام

### الزوج 👨 (صلاحية التعديل الكامل)

- **القوائم:** إضافة/تعديل/حذف المجموعات (خضراوات، فواكه، بقالة، منظفات، أدوية، دواجن، لحوم، أسماك…)
  وإضافة الأصناف والأسعار التقديرية. زر **＋** بجانب المجموعة يضيف صنفاً حتى لو كانت المجموعة مغلقة،
  وزر **🗑️** داخل الصنف يحذفه. كل صنف له صورة مصغّرة طبيعية لقطعة واحدة منه بخلفية بيضاء (مثلاً صورة طماطم حقيقية لا كلمة «طماطم»)،
  ويظهر اسم الصنف كاملاً بدون قصّ، ويمكن رفع صورة PNG مخصصة من زر 🖼️، وترتيب المجموعات والأصناف بالأسهم.
- **استيراد Excel:** من تبويب «القوائم» اضغط **استيراد من Excel**. العمود الأول = اسم المجموعة،
  الثاني = اسم الصنف، الثالث (اختياري) = السعر، الرابع (اختياري) = الترتيب، الخامس (اختياري) = رمز الإيموجي.
  يمكن أيضاً استخدام عناوين عربية في الصف الأول مثل «المجموعة» و«الصنف» و«السعر» و«الترتيب».
  اختر «إضافة للقائمة الحالية» أو «استبدال القائمة بالكامل». الملفات المدعومة: `.xlsx` و`.csv` (حتى 5 ميجابايت).
- **الطلبات:** شارة حمراء وإشعار على شاشة الهاتف بصوت مميز عند طلب جديد. افتح الطلب، ضع علامة ✅ بجانب كل صنف تم شراؤه.
  عند الانتهاء اضغط **إنهاء الطلب** ليظهر تقريران: المشتري وغير المشتري.
- **حذف البيانات:** حدّد الطلبات بعلامة ✓ ثم **حذف المحدد** لتوفير المساحة.
- **الإعدادات:** تغيير رمز الدخول للزوج أو للزوجة.

### الزوجة 👩

- اضغط **فتح طلب شراء جديد** → يظهر رقم الطلب وتاريخه.
- كل مجموعة تُفتح وتُغلق بالسهم الموجود في يسارها، وتظهر الأصناف بصورها المصغّرة والسعر التقديري واسم الصنف كاملاً؛ اكتبي الكمية في المربع بجانب الصنف،
  واكتبي ملاحظة أسفل الصنف إن أردتِ (مثلاً: «بدون بصل») — تظهر الملاحظة للزوج داخل الطلب.
- إن لم يوجد الصنف: زر **إضافة صنف مطلوب** أسفل المجموعة → اكتبي الاسم والكمية والسعر (اختياري).
  هذه الإضافة تخص هذا الطلب فقط ولا تغيّر القوائم الرئيسية.
- **مراجعة الطلب** تعرض الإجمالي والأصناف قبل الإرسال، ثم **إرسال للزوج**.
- من **طلباتي** يمكنك متابعة الطلبات واستكمال المسودات.

الإشعارات تظهر الآن على شاشة الهاتف لكلا الطرفين بصوت «جرس طلابات» مميز (`talabat_chime.wav`)
داخل APK عبر إضافات Capacitor المحلية، بدون إعداد FCM أو حساب Firebase.
للتأكد من الصوت: افتح **⚙️ الإعدادات** واضغط **🔔 إرسال إشعار تجريبي**.
للرجوع من أي شاشة استخدم زر **↩️** أعلى الشاشة أو زر زر الرجوع في الهاتف؛ زر **إلغاء** في النوافذ المنبثقة يعمل الآن.
تنبيه: الإشعار يُنشأ أثناء تشغيل التطبيق واتصاله بالسيرفر (فحص كل 10 ثوانٍ)؛
إذا كان التطبيق مغلقاً تماماً فلن يصله إشعار فوري. عند أول دخول اسمح بالإشعارات.

## 5) الأمان والنسخ الاحتياطي

- رموز PIN تُخزَّن كتجزئة PBKDF2 مع ملح، ولا تُحفظ كنص صريح.
- الجلسات موقّعة بـ `APP_SECRET` وصالحة 30 يوماً؛ يمكن تغييرها عبر `TOKEN_TTL_SECONDS`.
- الصور تُصغَّر تلقائياً إلى 320×320 وتُحفظ PNG داخل قاعدة البيانات (حد أقصى 2 ميجابايت للرفع).
- النسخ الاحتياطي:
  - SQLite: انسخ `server/data/talabat.db`.
  - PostgreSQL: استخدم أدوات النسخ في Neon.

السيرفر يقدّم الواجهة والبيانات من نفس النطاق، لذا لا توجد مشكلة CORS في الاستخدام الطبيعي.

## 6) استكشاف الأخطاء

| المشكلة | السبب والحل |
| --- | --- |
| التطبيق لا يتصل بعد تثبيت APK | افتح شاشة الدخول → إعدادات الاتصال → اكتب رابط السيرفر كاملاً بـ https |
| الرمز غير صحيح | تأكد من رمز الدور؛ إن نسيته راجع سجلات السيرفر عند أول تشغيل أو غيّره من إعدادات الزوج |
| الصورة لا تظهر | تأكد أن الصنف له صورة وأن التطبيق مسجّل الدخول (رابط الصورة يحمل الرمز) |
| الإشعار لا يصل فوراً | التطبيق يتحقق كل 10 ثوانٍ أثناء تشغيله؛ تأكد من السماح بالإشعارات ومن فتح التطبيق مرة بعد إرسال الطلب |
| الصوت مختلف أو غير مسموع | جرّب **إرسال إشعار تجريبي** من الإعدادات. النسخة الجديدة تستخدم قناة `talabat_alerts_v2`؛ إن كانت قديمة من تثبيت سابق احذف APK وأعد تثبيته ثم اسمح بالإشعارات |
| Render ينام ليلاً | أول طلب بعد النوم قد يستغرق ثوانٍ؛ هذا سلوك الخطة المجانية |
